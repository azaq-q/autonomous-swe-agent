# 90 秒项目演示脚本

本脚本用于录制简历项目演示。录制前启动演示环境，并准备一个拥有明确失败测试的公开演示仓库。

## 镜头顺序

1. **0–10 秒：项目定位**
   - 展示 Dashboard 和架构图。
   - 说明系统不是代码聊天框，而是可恢复、可审计的软件工程任务执行器。
2. **10–25 秒：创建真实任务**
   - 输入公开仓库、固定基础分支、Issue 描述和测试命令。
   - 提交任务并进入 Task Timeline。
3. **25–50 秒：自主执行**
   - 展示 clone、规划、代码检索、文件修改和沙箱测试事件。
   - 展示一次测试失败及日志反馈给 Coding Agent 的重试。
4. **50–65 秒：Review 与人工审批**
   - 展示结构化 Review 结论、风险项和返工轨迹。
   - 展示 patch SHA、token、成本和执行耗时。
5. **65–80 秒：GitHub 闭环**
   - 批准任务，展示幂等 commit、push 和 Draft PR URL。
   - 打开 PR，展示代码 diff 与通过的回归测试。
6. **80–90 秒：量化结果**
   - 展示真实 Benchmark 的解决率、P95 耗时和平均成本。
   - 明确容器演示与生产 microVM 沙箱之间的隔离边界。

## 录制验收

- 不出现 API Key、Git Token、个人目录或私有仓库 URL。
- 所有数字来自提交到仓库的原始报告。
- 视频、README 截图与案例 PR 使用同一个可复现 source commit。
- 最终成片控制在 90 秒以内，并提供中文字幕或英文字幕。
